## 🧩 About

**Grounded Trainer** is a curated list of Grounded open-source tools:

- **Mod Menus** — god mode, infinite stamina, item spawner, teleport, speed hack
- **UI Automation Bots** — auto-collect resources, auto-craft, input helpers for single-player study
- **Quality-of-Life Mods** — inventory expansion, map markers, HUD tweaks, overlay helpers
- **Research Frameworks** — training layouts and config notes for educational use

Based on publicly available community tools like **Grounded Modding Toolkit**, **Grounded Trainer**, and **QOL Mods**.
